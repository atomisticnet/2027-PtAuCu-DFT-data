# 2027-PtAuCu-DFT-data
This repository contains scripts and computational data used in the preparation of the following article: 

Just P. Jonasse, Kaifeng Zheng, Robin van der Kruit, Michael Wilms, Jan-Willem Lankman, Weixuan Huang, Mathilde Luneau, Petra E. de Jongh, 
Nongnuch Artrith, Anatoly I. Frenkel, and Jessi E. S. van der Hoeven;
Nanoscale Strain-Engineering Controls Hydrogen Reactivity in Nanoparticle Catalysts. ChemRxiv. 08 July 2026.
DOI: https://doi.org/10.26434/chemrxiv.15005827/v1

Please cite this reference if you make use of any parts of the source code or the density-functional theory (DFT) database.
